# 🎀 Missão Rosa — Uma Jornada pela Vida

Jogo educativo 2D sobre o Outubro Rosa, desenvolvido em HTML, CSS e JavaScript.

## Como jogar

- Use **A/D** ou as **setas** para movimentar a personagem.
- Pressione **Espaço** para pular.
- Colete laços rosas, desvie dos obstáculos e responda às perguntas.
- Em dispositivos com tela sensível ao toque, use os botões na tela.

## Como publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie os arquivos `index.html`, `README.md` e `.nojekyll` para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main`, a pasta `/ (root)` e clique em **Save**.
6. Aguarde a publicação. O endereço será `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
